# MODULE 1.1 --- JAVA PLATFORM FUNDAMENTALS

This directory contains resources, exercises, and implementations for Module 1.1 of the Java Fundamentals & OOP Deep Mastery syllabus.

## Topics Covered

- **1.1.1 JDK** - Java Development Kit fundamentals and tools
- **1.1.2 JRE** - Java Runtime Environment
- **1.1.3 JVM** - Java Virtual Machine execution
- **1.1.4 Java Source Compilation** - `javac` and compilation process
- **1.1.5 Bytecode and `.class` Files** - Understanding compiled output
- **1.1.6 JVM Execution Lifecycle** - Class loading, linking, initialization
- **1.1.7 Classpath / Module Path / Launcher** - Runtime configuration
- **1.1.8 Java Versioning and LTS** - Version management and compatibility
- **1.1.9 Module 1.1 Integrated Assessment** - Comprehensive exercises

## Study Path

1. Start with 1.1.1 (JDK fundamentals)
2. Progress through each subsection sequentially
3. Complete exercises in each directory
4. Use the integrated assessment to evaluate mastery
5. Review reference materials as needed

## Learning Outcomes

By completing this module, you should:

- [ ] Understand the JDK, JRE, and JVM relationship
- [ ] Be able to compile and run Java programs manually
- [ ] Understand bytecode and class file structure
- [ ] Comprehend the JVM execution lifecycle
- [ ] Manage classpath and module path effectively
- [ ] Make informed decisions about Java versions and runtime deployment
- [ ] Diagnose JVM and runtime issues
