Below is an ideal reading sequence for a developer with 5+ years of Java and Spring Boot experience. It avoids beginner-heavy material and progresses from senior-level Java craftsmanship to distributed systems, cloud architecture, security, observability, and technical leadership.

Recommended Reading Sequence
Phase 1: Senior-Level Java Foundation

Duration: 6 to 8 weeks

1. Effective Java, 3rd Edition

Author: Joshua Bloch
 Priority: Essential
 Read: Cover to cover, approximately 5 to 6 items per week

Start here because the book develops the judgment expected from a senior Java developer: object creation, API design, generics, lambdas, streams, exceptions, concurrency, inheritance, composition, and serialization. The current third edition covers through Java 9, so use it for enduring Java design principles rather than newer language features.

Apply it by:

Refactoring one existing Spring Boot service
Replacing unnecessary constructors with factories or builders
Improving immutability
Correcting equals() and hashCode()
Reviewing improper uses of Optional, streams, inheritance, and exceptions
2. Modern Java in Action, 2nd Edition

Authors: Raoul-Gabriel Urma, Mario Fusco, Alan Mycroft
 Priority: Essential

Concentrate on:

Functional interfaces
Lambdas and method references
Streams and collectors
Parallel streams
CompletableFuture
Functional programming techniques

Practical assignment: Build a data-processing application that uses streams, custom collectors, CompletableFuture, and asynchronous HTTP calls.

Because Java features evolve faster than books, supplement this with official JDK documentation for records, sealed classes, pattern matching, virtual threads, and structured concurrency.

3. Java Concurrency in Practice

Authors: Brian Goetz and others
 Priority: Essential, but read selectively

Despite being published in 2006, this remains highly valuable for concurrency fundamentals such as thread safety, state visibility, synchronization, task execution, cancellation, liveness, and concurrent program design. It predates virtual threads and modern Java releases, so combine its principles with current JDK documentation.

Recommended chapters:

Thread Safety
Sharing Objects
Composing Objects
Building Blocks
Task Execution
Cancellation and Shutdown
Thread Pools
Avoiding Liveness Hazards
Performance and Scalability

Practical assignment: Build a configurable task-execution engine using:

ExecutorService
CompletableFuture
Concurrent collections
Semaphores
Graceful shutdown
Timeouts and cancellation
Virtual threads as an alternative execution model
4. The Java Virtual Machine Specification or Inside the Java Virtual Machine

Priority: Reference and selective reading

Do not attempt to memorize the complete JVM specification. Focus on:

Class loading
Bytecode execution
Stack frames
Heap and metaspace
Java Memory Model
JIT compilation
Garbage collectors
Safepoints
Escape analysis

Practical assignment:

Generate heap dumps
Analyze memory leaks with Eclipse MAT
Compare G1 and ZGC
Use Java Flight Recorder and Java Mission Control
Investigate excessive allocation and long GC pauses

Why this sequence works

The sequence begins with Java correctness and maintainability, progresses to Spring implementation, then covers distributed systems and data trade-offs, followed by production operations, cloud deployment, architecture decision-making, and leadership. That ordering matches the progression from an experienced developer who implements features to a lead or architect who owns technical outcomes.
